# PlatformerGameProject

Онлайн-мультиплеерный 2D-платформер, разработанный на Unity.

## Описание

Проект представляет собой сетевой платформер, в котором игроки могут совместно проходить уровни в реальном времени.  
Основной фокус — реализация стабильного мультиплеера, сохранение прогресса игроков и взаимодействие с серверной частью.

Проект создавался в рамках изучения сетевых технологий в Unity и работы с облачным бэкендом.

## Основные возможности

- Мультиплеер в реальном времени
- Синхронизация позиций и состояний игроков
- Сохранение прогресса и данных игрока
- Работа с серверной логикой через Unisave
- Хранение данных в ArangoDB

## Технологии

- **Unity** — игровой движок
- **Photon PUN 2** — сетевой мультиплеер
- **Unisave** — облачный бэкенд для Unity
- **ArangoDB** — база данных

## Структура проекта

- `Assets/` — основной код, сцены, префабы и ресурсы
- Сетевая логика реализована через Photon PUN 2
- Серверная часть и работа с данными — через Unisave + ArangoDB

## Запуск проекта

1. Откройте проект в Unity (рекомендуемая версия — та, на которой проект создавался).
2. Убедитесь, что у вас настроены:
   - Photon App ID
   - Unisave проект
   - Доступ к ArangoDB
3. Откройте сцену лобби / главного меню и нажмите Play.

> **Примечание:** Для полноценной работы мультиплеера необходимы корректные ключи Photon и настроенный Unisave.

## Статус проекта

Проект находится в архивном состоянии. Разработка велась примерно 3–4 месяца.

## Автор

Разработано в рамках самостоятельного изучения сетевых технологий и бэкенда в Unity.
